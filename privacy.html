Boca Publisher

Halaman ini menjelaskan data apa yang diakses Boca Publisher dan bagaimana data tersebut diperlakukan.

1. Data yang diakses

  • Informasi dasar profil TikTok: open_id, username, display_name, dan avatar (scope user.info.basic).
  • Izin mengunggah video ke akun kamu (scope video.publish).

2. Data yang tidak dikumpulkan

  • Kami tidak mengumpulkan data pengguna lain.
  • Kami tidak membaca pesan, kontak, atau data sensitif lainnya.
  • Kami tidak menjual atau membagikan data ke pihak ketiga.

3. Penyimpanan

Token akses dan refresh token disimpan secara lokal pada perangkat milik pemilik akun dengan izin akses terbatas. Token tidak dikirim ke server pihak ketiga. Video diunggah langsung ke API resmi TikTok.

4. Retensi

Token disimpan sampai kamu mencabut otorisasi aplikasi. Log proses unggah disimpan lokal untuk keperluan troubleshooting.

5. Hak kamu

Kamu dapat mencabut akses kapan saja melalui pengaturan akun TikTok (Settings and privacy → Security → Manage app permissions). Setelah dicabut, aplikasi tidak dapat lagi mengakses akunmu.

6. Anak-anak

Layanan ini tidak ditujukan untuk pengguna di bawah usia 13 tahun.

7. Kontak

Pertanyaan tentang privasi dapat dikirim ke ideinaja.support@gmail.com.
